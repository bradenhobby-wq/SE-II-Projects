## User Stories
### US-3.1: Mark People Present
**As a** bible class teacher
**I want to** be able to mark people, whether a member or a guest, present
**So that** the church can know whose attendance has been slipping

**Priority:** P1
**Independent test:** Record people present for your class,  save changes
**Acceptance scenarios:** see ### US-3.1 under Acceptance
Criteria

### US-3.2: See Past Attendance Per Class
**As a** bible class teacher
**I want to** be able to see the total attendance for each of my past bible classes
**So that** I know if my attendance is dropping off and need to make changes

**Priority:** P1
**Independent test:** View the attendance of a bible teacher's past bible classes
**Acceptance scenarios:** see ### US-3.2 under Acceptance
Criteria

### US-3.3: See Past Attendance Lists
**As a** bible class teacher
**I want to** be able to see the attendance list for each of my past bible classes
**So that** I can see which specific people attended recent bible classes

**Priority:** P2
**Independent test:** View the attendance of a bible teacher's past classes, click on a previous class, view who attended past bible classes
**Acceptance scenarios:** see ### US-3.3 under Acceptance
Criteria

### US-3.4: See Bible Class Attendees' General Information
**As a** bible class teacher who is looking at past attendance
**I want to** be able to click on someone's profile to view their general information
**So that** I can easily contact someone who is struggling to attend class

**Priority:** P2
**Independent test:** View who attended past bible classes of a bible teacher, click on a profile, view their general information
**Acceptance scenarios:** see ### US-3.4 under Acceptance
Criteria

### US-3.5: See Bible Class Attendees' Attendance History
**As a** bible class teacher/church staff
**I want to** be able to click on someone's profile to view every day they went to a bible class
**So that** I can easily contact someone who is struggling to attend class

**Priority:** P1
**Independent test:** View who attended past bible classes of a bible teacher, click on a profile, view their attendance history
**Acceptance scenarios:** see ### US-3.5 under Acceptance
Criteria

### US-3.6: User Staff Adds Bible Classes
**As a** member of the church staff
**I want to** add a bible class and specify the teacher
**So that** bible class teachers can record attendance

**Priority:** P1
**Independent test:** Navigate to "Roles Management", add a bible class, check if the teacher has access to class attendance
**Acceptance scenarios:** see ### US-3.6 under Acceptance
Criteria
