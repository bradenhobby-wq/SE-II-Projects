## User Stories
### US-4.1: Staff With Admin Status Add Users
**As a** member of the church staff with admin privileges
**I want to** give church staff a link to create their account with a specific role
**So that** church staff can access the information they need to access


**Priority:** P1
**Independent test:** Add a user account to receive the "Create Account" email, check if they got the email
**Acceptance scenarios:** see ### US-4.1 under Acceptance
Criteria

### US-4.2: Staff With Admin Status Delete Users
**As a** member of the church staff with admin privileges
**I want to** delete user accounts when a person no longer works for the church
**So that** only church staff can access sensitive information


**Priority:** P1
**Independent test:** Delete an account, check if its username and password still work
**Acceptance scenarios:** see ### US-4.1 under Acceptance
Criteria


### US-4.3: Staff With Admin Status Edit Users' Roles
**As a** member of the church staff with admin privileges
**I want to** be able to change the roles of users
**So that** authorization can adjust to staff changes


**Priority:** P1
**Independent test:** Edit someone's role, and ensure it actually changed
**Acceptance scenarios:** see ### US-4.2 under Acceptance
Criteria


### US-4.4: Users Use The Forgot Password Option
**As a** member of the church staff who forgot my password
**I want to** change my password
**So that** I can retain access to my account

**Priority:** P1
**Independent test:** Fill out the 
"forgot password" form, and click submit
**Acceptance scenarios:** see ### US-4.4 under Acceptance
Criteria


### US-4.5: Users Log In With Correct Credentials
**As a** user with an account
**I want to** sign in with my username and password
**So that** I can do my job

**Priority:** P1
**Independent test:** Login to a valid account
**Acceptance scenarios:** see ### US-4.5 under Acceptance
Criteria


### US-4.6: Users See The Correct Dashboard
**As a** person with a valid account
**I want to** be able to do access the tasks I am authorized to use
**So that** I can access the services I need to

**Priority:** P1
**Independent test:** Log into accounts with different roles, check if they have access to the right services
**Acceptance scenarios:** see ### US-4.6 under Acceptance
Criteria
